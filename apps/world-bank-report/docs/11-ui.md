# UI

Three screens, shared shell. Minimal research-tool look; reuse the shadcn
setup and theme from interview-prep / gpo-report.

## 1. Ask — `/`

```text
┌───────────────────────────────────────────────────────────────────────────────┐
│ World Bank Report · Q&A           Ask   Map   Inspect          Preset [B5 ▾]  │
├───────────────────────────────────────────────────────────────────────────────┤
│ ┌─────────────────────────────────────────────────────────────────┐  [Ask]    │
│ │ Ask about the report…                                           │           │
│ └─────────────────────────────────────────────────────────────────┘           │
│ Try: [sample] [sample] [sample]                                               │
│                                                                               │
│ Understood as: comparison · SAR, SSA · 2025 · tables      (from query analysis)│
│                                                                               │
│ ┌──────── Answer ──────────────────────┐ ┌──── Sources by section ──────────┐ │
│ │ Growth in South Asia is projected …  │ │ ▾ Regional Outlooks › South Asia │ │
│ │ (South Asia › Outlook, p. 87) while  │ │   [1] Outlook · p. 87–88 · text  │ │
│ │ in Sub-Saharan Africa … (p. 102)     │ │   [2] Table 2.5.1 · p. 89 · table│ │
│ │                                      │ │ ▾ Regional Outlooks › SSA        │ │
│ │ | Region | 2025f | 2026f |           │ │   [3] Outlook · p. 101–102       │ │
│ │ | SAR    | …     | …     |           │ │                                  │ │
│ │                                      │ │                                  │ │
│ │ 6.4 s · 9.1k ctx tokens · B5         │ │                                  │ │
│ └──────────────────────────────────────┘ └──────────────────────────────────┘ │
│ ▸ Retrieval trace                                                             │
│   analyze 610ms → search 140ms (2 queries, 0 relaxations) → rerank 1.9s       │
│   (30→8) → context 12ms (4 blocks, 9.1k/12k tok, 1 dropped) → generate 3.1s   │
└───────────────────────────────────────────────────────────────────────────────┘
```

- Citation badges show `Section · p. N`; tables show `Table 2.5.1 · p. 89`.
  Click → highlights the source block; table sources render as real tables.
- "Understood as" chip row shows query analysis (B4+); hidden for B0–B3.
- Trace panel expands to per-stage details (candidates with vRank/kRank, rerank
  scores, which filters relaxed, which blocks dropped for budget).
- Preset selector lets a reviewer compare B0 vs B5 live on the same question.
- States: empty, streaming, refusal (muted), error with retry; sources collapse
  under the answer on mobile.

## 2. Document Map — `/map`

```text
┌───────────────────────────────┬───────────────────────────────────────────────┐
│ ▾ Report                       │ Regional Outlooks › South Asia › Outlook       │
│   ▸ Front matter               │ pp. 87–88 · 1,940 tokens · 6 chunks            │
│   ▸ 1 Global Outlook           │ Regions: SAR · Years: 2024, 2025, 2026         │
│   ▾ 2 Regional Outlooks        │                                               │
│     ▸ East Asia and Pacific    │ Summary (generated, not cited)                 │
│     ▾ South Asia               │ Growth in South Asia is projected …            │
│        Recent developments     │                                               │
│      ● Outlook                 │ Chunks                                         │
│        Risks                   │ #412 text  p.87  "…"                           │
│        Table 2.5.1             │ #413 text  p.87  "…"                           │
│   ▸ Statistical Appendix       │ #418 table p.89  Table 2.5.1 …                 │
└───────────────────────────────┴───────────────────────────────────────────────┘
```

Shows the parsed structure — the first place to look when retrieval misses a
section. Fallback pages (`parse_source = text_layer`) are flagged ⚠️.

## 3. Inspect — `/inspect`

- Query + preset → full retrieval with no generation.
- Tabs per stage: Analysis (JSON) · Candidates (table: rank, score, vRank, kRank,
  type, section, pages, regions, years) · Rerank (score per candidate, kept/dropped)
  · Context (assembled blocks with token counts, in final order, budget bar).
- "Compare presets" toggle: two presets side by side on the same query.
- Chunk browser: by page, section, or type, showing `content` and `embed_text`.
