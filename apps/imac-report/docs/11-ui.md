# UI

Three screens, shared shell, same shadcn theme as the other POD projects.

## 1. Ask — `/`

```text
┌───────────────────────────────────────────────────────────────────────────────┐
│ iMac Environmental Report · Q&A     Ask  Explorer  Inspect     Preset [M4 ▾]   │
├───────────────────────────────────────────────────────────────────────────────┤
│ ┌───────────────────────────────────────────────────────────────┐  [Ask]      │
│ │ Ask about the report…                                         │             │
│ └───────────────────────────────────────────────────────────────┘             │
│ Try: [sample] [sample] [sample]                                               │
│ Looking in: chart · footnote · variant: two ports          (query analysis)   │
│                                                                               │
│ ┌──── Answer ──────────────────────────┐ ┌──── Sources ──────────────────────┐ │
│ │ Production accounts for 70% of the   │ │ [1] 📊 Chart · p.3                 │ │
│ │ life cycle carbon emissions [1].     │ │  Life cycle carbon emissions      │ │
│ │ This assumes a four-year use period  │ │  ┌ re-rendered ┐ ┌ original ┐     │ │
│ │ for the first owner [2].             │ │  │ bar chart   │ │  crop    │     │ │
│ │                                      │ │  └─────────────┘ └──────────┘     │ │
│ │ 5.8 s · 3 sources · 1 image · M4     │ │ [2] ¹ Footnote 1 · p.3             │ │
│ └──────────────────────────────────────┘ │  "Use phase assumes …"            │ │
│ ▸ Retrieval trace                        │  ↳ referenced by: chart [1]       │ │
│                                          │ [3] ▦ Table · p.4 Energy …        │ │
│                                          │  (table, hit row highlighted)     │ │
│                                          └───────────────────────────────────┘ │
└───────────────────────────────────────────────────────────────────────────────┘
```

Source card per type:

| Type | Card shows |
| --- | --- |
| Table | Rendered table; hit rows highlighted; notes; toggle to original crop |
| Chart | Recharts re-render of **labelled** values (estimated values shown hatched/greyed with "~") **next to** the original crop |
| Footnote | Marker + text + "referenced by" links |
| Callout | Figure + text + crop |
| Text | Excerpt + page |

Citation badges show a type icon + page (`📊 p.3`). Clicking → card highlights;
"View on page" opens Explorer at that element.

If the model reported an image/extraction disagreement, a small warning appears
on that source.

## 2. Document Explorer — `/explorer`

```text
┌──────────────────────────────────────────┬────────────────────────────────────┐
│ Page [3 ▾]  Strategy [X2 ▾] [compare X1] │ Element: chart · "Life cycle …"     │
│ ┌──────────────────────────────────────┐ │ bbox [120, 80, 520, 940]           │
│ │  page image                          │ │ Fidelity ✓ (labels in text layer)  │
│ │   ┌──────────┐  ← text (grey)        │ │                                    │
│ │   └──────────┘                       │ │ Series / points                    │
│ │   ┌────────────────────┐ ← chart     │ │ Production   70%   labelled        │
│ │   │ (blue box, selected)│            │ │ Transport    x%    labelled        │
│ │   └────────────────────┘             │ │ Use          xx%   labelled        │
│ │   ┌──────────┐ ← table (green)       │ │ End of life  <1%   labelled        │
│ │   ¹ footnote (orange)                │ │                                    │
│ └──────────────────────────────────────┘ │ Footnotes: ¹ → "Use phase assumes…" │
│ Legend: text table chart footnote callout│ Derived chunks (5) ▸               │
│ ⚠ 1 flagged element on this page         │ Ground truth diff ▸ (if labelled)   │
└──────────────────────────────────────────┴────────────────────────────────────┘
```

- Boxes coloured by type; click selects an element.
- **Compare strategies**: overlay X1 vs X2 boxes, side-by-side extracted data, and
  ground-truth diff where available — the visual half of the extraction eval.
- Flagged elements (fidelity / unresolved markers) listed per page.
- Footnote links drawn as thin lines from marker to footnote on the page.

## 3. Inspect — `/inspect`

Same as world-bank-report: query + preset → stage tabs (Analysis · Candidates
with chunk kind, vRank/kRank, boost · Elements after expansion · Context with
token bar and which images were attached). Chunk browser filterable by
`chunk_kind`.
