# UI

Two screens. Clean and minimal, like a research tool, not a chatbot. Reuse
interview-prep's shadcn setup, typography, and light/dark theme.

## 1. Ask — `/`

```text
┌──────────────────────────────────────────────────────────────────────────┐
│ GPO Annual Report · Q&A                         Inspect   Run: 3f2a ● v0 │
├──────────────────────────────────────────────────────────────────────────┤
│  ┌────────────────────────────────────────────────────────────┐ [Ask]    │
│  │ Ask a question about the report…                           │          │
│  └────────────────────────────────────────────────────────────┘          │
│  Try: [What was …?] [How many …?] [Summarise …]   ← sample questions     │
│                                                                          │
│ ┌──────────── Answer ─────────────────┐ ┌──────── Sources (6) ─────────┐ │
│ │ The report states that … (p. 12)    │ │ 1  p. 12–13 · Financial …    │ │
│ │ (p. 4).                             │ │    0.81  "Revenue for FY…"   │ │
│ │                                     │ │ 2  p. 4 · Director's Message │ │
│ │ • detail (p. 12)                    │ │    0.74  "…"                 │ │
│ │                                     │ │ 3  p. 22 · …   (not cited)   │ │
│ │ 2.1 s · 6 chunks · vector           │ │                              │ │
│ └─────────────────────────────────────┘ └──────────────────────────────┘ │
└──────────────────────────────────────────────────────────────────────────┘
```

Behaviour:
- Sources appear as soon as the `sources` event arrives; the answer streams in after.
- `[n]` in the answer renders as a **page badge** (`p. 12`, or `p. 12–13`). Hover shows
  the section; click scrolls to and highlights the chunk in the sources panel.
- Cited sources are marked; uncited ones are dimmed but visible (useful for debugging).
- A source card expands to the full chunk text.
- Refusal renders in a muted info style, not as an error.
- Footer line: latency, chunk count, retrieval mode.
- Sample chips come from in-scope `provided` questions in `eval/questions.json`.
- States: empty (intro + chips), loading (skeleton sources, typing cursor), error
  (friendly Gemini/DB message + retry), refusal.
- On mobile, sources collapse into an accordion under the answer.

## 2. Inspect — `/inspect`

Developer screen: retrieval only, no generation.

```text
┌──────────────────────────────────────────────────────────────────────────┐
│ Query [______________________________]  k [6▾]  mode [vector▾]  [Search] │
│ Run: 3f2a (chunk 3200/400, 312 chunks)   embed 120 ms · search 35 ms     │
├──────────────────────────────────────────────────────────────────────────┤
│ Rank  Score  vRank kRank  Pages   Section                 Preview        │
│ 1     0.81   1     3      12–13   Financial › Revenue     "Revenue …"    │
│ 2     0.74   2     –      4       Director's Message      "…"            │
├──────────────────────────────────────────────────────────────────────────┤
│ Chunk browser   Page [14 ▾]  ‹ ›                                         │
│ #41 p.14 · Financial Highlights › Revenue · 3104 chars                   │
│ <full content>                                                           │
│ ▸ show embed_text                                                        │
└──────────────────────────────────────────────────────────────────────────┘
```

- vRank / kRank columns only in hybrid mode.
- Chunk browser answers "what does the pipeline think page 14 says?" — the first
  thing to check when a page is never retrieved.

## 3. Components

| Component | Notes |
| --- | --- |
| `QuestionForm` | Textarea, Enter to submit, Shift+Enter newline, disabled while streaming |
| `SampleQuestions` | Chips, click fills and submits |
| `Answer` | Markdown render, citation badge replacement, refusal style |
| `SourcesPanel` / `SourceCard` | Rank, page badge, section, score bar, expand |
| `RetrievalTable` | Sortable table |
| `ChunkBrowser` | Page selector, chunk list |
